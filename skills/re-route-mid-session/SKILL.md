# Skill: re-route-mid-session

**When:** Mid-session the demand type changes (e.g. implementation → audit, or rules edit → decision).

## Steps

1. Stop current micro-plan; do not drag wrong context.
2. Re-read Process Caller route table; pick the new route.
3. Drop unrelated skill bodies from working memory (pull, don't push).
4. Update task overview “Status / route” if a task folder exists.
5. Continue with the new first-pull set only.
6. If uncertainty remains, one clarifying question.

## Do not

- Keep two conflicting procedures active.
- Create a second route table anywhere.
